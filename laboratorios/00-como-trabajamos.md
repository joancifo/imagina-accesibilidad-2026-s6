## Herramientas de Figma que vas a usar

| Qué | Cómo |
|---|---|
| **Medir el contraste** | Selecciona la capa → panel derecho → **Relleno** → clic en la muestra de color → botón de contraste (**«Check color contrast»** en inglés). Elige la categoría (texto normal, texto grande, gráficos). Necesita permiso de edición. |
| **Añadir una variante** | Selecciona el conjunto de componentes (borde morado discontinuo) → **+** en el panel derecho, o duplica una variante (Ctrl/Cmd + D) y cambia su nombre `Estado=Foco`. |
| **Descripción de un componente** | Selecciona el componente **principal** → panel derecho → campo *Descripción*. |
| **Instancia del kit** | Panel **Recursos (Assets) → Local**, o copia una anotación del kit y pégala. Cambia el texto con doble clic. |
| **Altura automática** | Selecciona un texto → panel de texto → *Altura automática* (para que crezca y no se corte). |
| **Plugins (retos)** | Menú de recursos → **Plugins**: *Color Blind* (daltonismo), *Stark* o *Able* (contraste), *Include* (anotaciones). |

## ¿Atascados?
